# ORX toolchain roadmap

- freeze ORX v1 container/ABI compatibility rules
- resource table for icons, strings and embedded files
- relocatable/native x86_64 payload option alongside Orion VM64 bytecode
- debug symbols and source mapping
- deterministic builds and package hashes
- app signing and trust metadata
- permission/capability linting
- linker/import table for Orion system services
- package repository metadata format
- `orx test` host-side VM test harness
- integration tests against the UN_Orion loader once disk application loading lands
